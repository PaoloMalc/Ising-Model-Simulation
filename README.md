Stochastic Simulation Methods in Physics: 2D/3D Ising ModelThis repository contains the final project for the "Stochastic Simulation Methods in Physics" course. The project explores the thermodynamic behavior of the Ising model on regular lattices using Markov Chain Monte Carlo (MCMC) methods, with a strong focus on overcoming critical slowing down via the Wolff cluster algorithm.Features and ImplementationThe project is structured around several core computational physics challenges:Wolff Algorithm Validation: Implementation of the Wolff cluster algorithm for a 2D homogeneous ferromagnetic Ising model. The simulated magnetization is verified against Onsager's exact analytical solution for $\beta > \beta_c$:$$M(\beta) = \left[ 1 - \sinh(2\beta)^{-4} \right]^{1/8}$$MCMC Comparison: Analysis of thermalization times, comparing the plain Metropolis algorithm with the Wolff algorithm near criticality.3D Lattice Extension: Numerical estimation of the critical inverse temperature $\beta_c$ for the 3D infinite hypercubic lattice.Heterogeneous Couplings: Generalization of the detailed balance condition using link-dependent probabilities $p_{ij}$ to simulate asymmetric couplings ($J_v \neq J_h$) and random uniform interactions $J_{ij} \in [0.5, 1.5]$.External Fields: Simulation of systems with external fields $h_i > 0$ using a generalized $N+1$ "ghost spin" topological approach.Spin Glasses & Random Fields (Optional): Exploration of arbitrarily signed couplings (Edward-Anderson model) and the Random Field Ising Model (RFIM)
